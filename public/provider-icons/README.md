# Provider marks

These marks identify the model provider in the benchmark run list.

- `openai.svg`: OpenAI favicon from OpenAI's asset CDN.
- `anthropic.svg`: Anthropic mark from Simple Icons.
- `deepseek.svg`: DeepSeek mark from Simple Icons.
- `xai.svg`: xAI mark from Wikimedia Commons, sourced from xAI.
- `opencode.svg`: OpenCode mark from Simple Icons.
- `kimi.svg`, `meta.svg`, and `qwen.svg`: model-family marks from Lobe Icons,
  imported from Puzzle Runner's pinned `@lobehub/icons-static-svg` 1.94.0 assets.
